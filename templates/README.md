- **ID** — 같은 A/B 묶음은 같은 ID를 씁니다. 파일명으로 구분합니다.
- **분류** — `콜드메일` 은 먼저 보내는 영업 메일, `발신템플릿` 은 요청에 응답해
  보내는 메일입니다.
- **그룹** — 이름이 같으면 표에서 떨어져 있어도 한 묶음으로 보입니다.
  묶음의 자리는 그 이름이 처음 나온 줄, 묶음 안 순서는 표의 순서를 따릅니다.
- **시안** — A/B 변형. 같은 그룹·이름의 줄이 여럿이면 한 항목으로 묶이고
  `시안 A B` 토글이 생깁니다. 변형이 없으면 `-` 로 둡니다.
  **제목만 다른 A/B도 파일을 따로 둡니다** — 각 파일이 자기 `<title>` 과
  `utm_content` 를 가지므로, 에디터에 보이는 코드가 곧 보낼 코드입니다.
  검증은 같은 묶음의 시안끼리 본문(제목·UTM 제외)이 같은지 `제목만 다름` /
  `본문도 다름` 으로 알려 줍니다. 제목만 다를 셈이었는데 `본문도 다름` 이
  나오면 한쪽만 고친 것입니다.
- **상태** — 어느 값이든 UTM 설정은 그대로 남습니다.
  - `사용중` — 지금 쓰는 시안
  - `미사용` — 시안은 있으나 아직 쓰기 전. 목록에 보이고 `미사용` 배지가 붙습니다
  - `운영종료` — 집행을 마친 시안. 목록에서 숨겨지고 `운영종료 N` 을 눌러야 보입니다
- **UTM** — 파일 안 링크에 적힌 값을 여기에 **그대로 옮겨 적습니다.** 문서와 파일이
  어긋나면 검증에서 막습니다. 링크마다 값이 갈리는 시안은 `-` 로 비워 둡니다.

각 `.html` 은 **한 겹짜리 문서**여야 합니다. `<!DOCTYPE>`·`<html>`·`<body>` 가
두 번 이상 나오면 배포가 막힙니다. 브라우저는 겹친 문서를 너그럽게 렌더하지만
메일 클라이언트는 어느 `<head>` 를 살릴지 제각각이라, 미리보기만 멀쩡하고 실제
발송에서 깨질 수 있습니다.
